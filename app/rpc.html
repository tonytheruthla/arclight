Why we run this

We build a launchpad and a terminal on Arc. Both were unusable while the only available endpoints were rate-limiting under mild load — our terminal spent weeks showing skeletons because a stalled RPC never returns an error, it just never returns.

Fixing that for ourselves meant caching, timeouts and failover. Running it for everyone else costs us almost nothing more, and a chain where nobody can reliably read state is a chain where nothing gets built. So it's free, with no key and no sign-up.

What we log: nothing.

  • No request bodies. We never see or store which contracts you call.
  • No wallet addresses.
  • No IP addresses. IPs are hashed with a random salt that exists only in memory for rate limiting, and is destroyed when the process restarts.
  • No database. There is nowhere for data to accumulate.

That's checkable, not a promise — read the live policy endpoint and the source.

An RPC provider is in a position to see a lot. If you're doing something where that matters, don't take our word for it — run your own node, or use an endpoint you control. That advice is against our interest and it's still the right advice.
